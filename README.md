# PocketForge

PocketForge is a beginner-first Android app builder. Open the app, choose a
starter (or name an idea), and use the full-screen preview as the actual app.
The editor accepts plain-language changes such as “make it green,” “rename the
app to Family Budget,” and “add a screen called shopping.” Starter apps work
offline with no account or AI key. Optional AI providers broaden the design
assistant; the app keeps keys encrypted on the device.

The no-code studio stores a validated declarative design rather than exposing
source files. Entries are saved separately for each project, destructive screen
or field replacement is rejected, recent versions can be restored, and a JSON
design backup can be shared. The advanced conversational agent workspace,
protected repository Autopilot, build connectors, and updater remain available
from the studio.

See [docs/NO_CODE_STUDIO.md](docs/NO_CODE_STUDIO.md) for the safety and
verification contract.
